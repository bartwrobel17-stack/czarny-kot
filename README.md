# Czarny Kot — salon fryzjerski

Demo strony internetowej dla salonu Czarny Kot, Promień 33, Wrocław.

## Status
- Strona główna: gotowa
- Galeria: wersja demonstracyjna
- Kontakt: gotowy
- Rezerwacje: przygotowane miejsce, bez systemu rezerwacji
- Płatności: niepodłączone
- Panel właściciela: demonstracyjny ekran, bez prawdziwego uwierzytelniania

## Dane potrzebne od właściciela do wersji produkcyjnej
1. Pełny cennik i lista usług.
2. Godziny otwarcia i dni wolne.
3. Aktualne logo, zdjęcia salonu i zdjęcia realizacji.
4. Informacja, kto obsługuje klientów i ile stanowisk jest dostępnych.
5. System rezerwacji, z którego właściciel już korzysta, albo decyzja o nowym systemie.
6. Zasady rezerwacji: czas usługi, bufor, odwołania, nieobecności.
7. Operator płatności, np. Przelewy24/Stripe, oraz dane potrzebne do konfiguracji konta.
8. Dane do faktury firmy i zgody/teksty prawne potrzebne przy formularzach.
9. Docelowa domena, jeśli właściciel ją posiada.
10. Dostęp do Google Business/Map tylko jeśli chce mieć zarządzane linki i dane wizytówki.

## Następny etap
Po zebraniu tych danych można dodać prawdziwe rezerwacje, płatności i bezpieczny panel administratora z bazą danych.
